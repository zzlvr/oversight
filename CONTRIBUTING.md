# Contributing

Issues and pull requests are welcome. Please write them in English.

- Logic goes into `Packages/OversightCore` with tests. Run `swift test --package-path Packages/OversightCore`.
- The Xcode project is generated from `project.yml` with XcodeGen and is not committed.
- Add new interface strings to `App/Localizable.xcstrings`. New translations are welcome.
- Never commit API keys, certificates or provisioning profiles.
- Keep commit messages to one short line.
